# Credit Risk Assessment

Repositori ini berisi semua kode, *notebook*, dan aset yang digunakan dalam proyek penilaian risiko kredit menggunakan dataset Lending Club, sebagai bagian dari program Rakamin IDX Partners Data Science Project.

## Struktur Repositori

Proyek ini diorganisir sebagai berikut:

| Folder | Deskripsi |
| :--- | :--- |
| `assets` | File pendukung seperti gambar atau visualisasi. |
| `input` | Data mentah dan data yang sudah diproses awal (parquet/csv). |
| `models` | Model ML yang disimpan (file joblib). |
| `notebooks`| Eksplorasi data, EDA, dan notebook analisis utama. |
| `scripts` | *Python scripts* untuk mendukung pelatihan. |
| `src` | Kode modular (utils.py, models.py, dll.). |

---

## Memulai

Untuk mereplikasi hasil, pastikan memiliki data yang diperlukan di dalam folder `input` dan ikuti urutan eksekusi yang dijabarkan dalam notebook 01-03.
